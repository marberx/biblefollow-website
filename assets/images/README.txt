BIBLEFOLLOW WEBSITE IMAGE ASSETS

Place final optimized BibleFollow assets in this folder.

Recommended filenames:

logo.webp
app-icon.webp
hero-phone.webp
screen-reader.webp
screen-ai.webp
screen-daily.webp
screen-prayer.webp
og-image.webp

Recommended formats:

WebP for website images.
SVG for vector logos where appropriate.

Avoid unnecessarily large image files.

Use original BibleFollow app screenshots rather than
low-resolution screenshots downloaded from the App Store.

The current V1 website uses CSS-created phone mockups,
so images are not required for the website to load.
