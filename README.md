## Technology

The website is intentionally lightweight.

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages compatible
- No database
- No build process required

## Important

Before production launch:

1. Add final BibleFollow branding.
2. Replace mockup screens with real app screenshots if desired.
3. Privacy Policy lives at https://bibleoffice.com/privacy_policy.html (privacy.html redirects there).
4. Terms live at https://bibleoffice.com/terms_conditions.html (terms.html redirects there).
5. Confirm support/contact details.
6. Connect biblefollow.app.
7. Enable HTTPS.
8. Test desktop and mobile.
9. Validate sitemap.
10. Connect Google Search Console.
